\# User Research → User Journey → Problem Definition Framework



\## 1. Identify the User



Who experiences the problem?



\## 2. Identify the Goal



What is the user trying to accomplish?



\## 3. Understand Current Behavior



What does the user do today?



\## 4. Map the User Journey



List the major steps from starting point to desired outcome.



\## 5. Identify Pain Points



Where does the user experience:



\- Time

\- Effort

\- Cost

\- Confusion

\- Errors

\- Friction

\- Inconsistency



\## 6. Identify Root Cause



Why does the problem occur?



Avoid stopping at symptoms.



\## 7. Define the Most Important Problem



Which problem creates the greatest user/business impact?



\## 8. Identify Evidence



Validate through:



\- User interviews

\- Observation

\- Surveys

\- Analytics

\- Time-on-task

\- Support feedback

\- Usability testing



\## 9. Write the Problem Statement



\[User] struggles to \[achieve outcome] because \[root cause], resulting in \[impact].



\## 10. Treat It as a Hypothesis



The problem statement should be validated rather than assumed to be true.
