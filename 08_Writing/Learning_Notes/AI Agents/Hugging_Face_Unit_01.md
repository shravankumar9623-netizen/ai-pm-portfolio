# Hugging Face – Unit 1

## What is an AI Agent?

An AI Agent is an AI system capable of reasoning, planning and taking actions using external tools to achieve a goal.

## Difference from a normal LLM

LLM:
Input → Output

Agent:
Goal → Reason → Select Tool → Execute → Observe → Continue → Final Answer

## Product Insight

Agents are useful when tasks require multiple steps, external APIs, or iterative decision making.

## My AI Product

The Automated Video Solution Generator could evolve into an AI Agent that:

- Reads uploaded PDFs
- Generates scripts
- Chooses narration style
- Reviews quality
- Exports the final video automatically
