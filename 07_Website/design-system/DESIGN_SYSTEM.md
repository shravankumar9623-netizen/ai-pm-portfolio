# Website Design System

## Design Principles

1. Evidence before decoration.
2. Clear recruiter scanning within the first screen.
3. Accessible typography, contrast, focus states, and navigation.
4. Consistent status labels for observed facts, targets, hypotheses, and validated outcomes.
5. Progressive disclosure: summary first, detailed artifact second.

## Foundations to Define in Figma

### Color Roles

- Background
- Surface
- Primary text
- Secondary text
- Brand accent
- Border
- Success or validated
- Target
- Hypothesis
- Warning or risk

Final color values require accessibility testing before implementation.

### Typography Roles

- Display heading
- Page heading
- Section heading
- Body
- Supporting text
- Label
- Code or metric

### Spacing and Layout

- Use a consistent spacing scale.
- Define desktop, tablet, and mobile content widths.
- Keep long case-study text at a readable line length.
- Use consistent vertical rhythm between headings, evidence, diagrams, and tables.

## Core Components

- Header and navigation
- Hero section
- Project card
- Artifact card
- Metric and evidence card
- Status badge
- Timeline
- Architecture diagram frame
- Callout
- Button and text link
- Footer and contact block

## Accessibility Checklist

- WCAG-compliant color contrast
- Visible keyboard focus
- Semantic heading hierarchy
- Descriptive link labels
- Alternative text for meaningful images
- Tables with headers
- Reduced-motion support
- Responsive touch targets
