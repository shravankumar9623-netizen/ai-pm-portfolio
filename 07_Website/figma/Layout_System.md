# Portfolio Layout System

The website uses a responsive shell, clear page header, modular content sections, cards and visible actions. Recruiter-critical information follows this order: positioning, selected products, evidence limits, capabilities, resume and contact.

## Responsive rules

- Maintain readable line length and a single-column fallback.
- Keep navigation available on small screens without horizontal overflow.
- Present case studies as scannable cards before detailed evidence.
- Ensure focus states and semantic headings remain visible.
- Do not rely on color alone for status or evidence classification.

This document records the intended layout system. It does not claim that a public Figma prototype exists.
