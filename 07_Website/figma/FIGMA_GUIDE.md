# Figma Guide

## File Organization

Create one Figma file with these pages:

1. Cover and documentation
2. Foundations
3. Components
4. Desktop wireframes
5. Mobile wireframes
6. High-fidelity pages
7. Prototype
8. Archive

## Component Workflow

- Define color, typography, spacing, radius, and elevation variables first.
- Build components with Auto Layout.
- Use variants for size, state, and evidence classification.
- Name layers and components consistently.
- Keep website copy linked to `WEBSITE_CONTENT_MAP.md`.
- Record the source artifact beside every case-study section during design review.

## Required Frames

- Home: desktop and mobile
- About: desktop and mobile
- Case-study index: desktop and mobile
- Flagship case study: desktop and mobile
- Resume: desktop and mobile
- Writing index: desktop and mobile
- Contact: desktop and mobile

## Handoff Checklist

- Components use shared variables and styles.
- Responsive behavior is annotated.
- Hover, focus, active, loading, and empty states are documented.
- Images and icons have export settings.
- Accessibility notes are attached to relevant components.
- Prototype paths cover recruiter navigation from Home to case study to resume/contact.
