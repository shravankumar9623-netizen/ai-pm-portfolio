\## What I Learned



I learned that AI Search is not simply an LLM connected to a search box.



It is a product pipeline involving:



Query Understanding

→ Intent Detection

→ Retrieval

→ Ranking

→ Reranking

→ Grounding

→ Generation

→ Citations

→ User Action



The most important concept was:



Retrieval Quality ≠ Answer Quality.



A fluent answer can still be based on poor retrieval.
