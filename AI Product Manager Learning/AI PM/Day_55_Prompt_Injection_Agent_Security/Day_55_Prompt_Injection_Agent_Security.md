\# Day 55 — Prompt Injection \& Agent Security



\## Objective



Understand how prompt injection and excessive agent permissions can create security risks in AI products.



\## Prompt Injection



Prompt injection is an attempt to manipulate an AI system through crafted input or untrusted content so that it behaves contrary to its intended instructions or boundaries.



\## Direct Prompt Injection



The attacker directly interacts with the AI.



\## Indirect Prompt Injection



Malicious instructions are placed inside content the AI later consumes.



Examples:



\- Emails

\- Web pages

\- PDFs

\- Documents

\- Customer messages



\## Why Agents Increase Risk



Agents may:



\- Read data

\- Call tools

\- Modify records

\- Send messages

\- Perform actions



Therefore:



Prompt Injection

\+

Tool Access

=

Potentially consequential behavior



\## Core Security Principles



\- Least privilege

\- Permission boundaries

\- Input validation

\- Output validation

\- Tool restrictions

\- Sandboxing

\- Human approval

\- Monitoring

\- Auditability



\## Coach Lesson



Capability without permission is not product design.
