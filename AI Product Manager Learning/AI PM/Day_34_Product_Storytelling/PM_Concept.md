\# PM Concept — User Journey Mapping



\## Definition



A User Journey represents the complete experience a user goes through while trying to achieve a goal.



\## PM Objective



Use the journey to identify user pain points, prioritize opportunities, and determine where the product can create meaningful value.



\## Framework



User Goal

↓

Trigger

↓

User Actions

↓

Touchpoints

↓

Pain Points

↓

Friction

↓

Opportunities

↓

Product Solution

↓

Expected Outcome



\## Key Principle



Don't start with the feature.



Start with the user's journey.



\## Journey vs Flow



User Journey:

Focuses on the user's overall experience.



User Flow:

Focuses on how the user moves through the product.



\## Application to AI Educational Video Generator



User Goal:

Create a high-quality educational video solution.



Major journey:



Question

↓

Solution

↓

Explanation

↓

Annotation

↓

Narration

↓

Synchronization

↓

Rendering

↓

Review

↓

Publishing



Major pain points:



\- Manual production effort

\- Repetitive explanation work

\- Manual annotation

\- Narration effort

\- Synchronization effort

\- Production inconsistency

\- Scaling difficulty



\## Product Opportunity



Automate repetitive video-production activities while keeping faculty involved in quality control.



\## PM Learning



A strong PM does not begin with:



"What feature should we build?"



A strong PM begins with:



"What is the user trying to accomplish, where does the journey break down, and which problem is worth solving?"
