# Day 49 — AI Product Economics

**Evidence classification:** CONCEPTUAL product-economics guidance. All quantities below are SIMULATED learning examples, not observed product results.

## Core Principle

AI products have variable economics because model inference, tools, retrieval, search, storage and human review can create costs for every interaction.

Therefore an AI PM must understand unit economics.

## Traditional SaaS

User

→ Software

→ Result

AI Product

User

→ Model

→ Tools

→ Retrieval

→ Model

→ Action

→ Result

Each additional operation can create cost and latency.

## Important Metrics

- Cost per request

- Cost per user

- Cost per successful task

- Cost per successful resolution

- Human escalation cost

- Total cost-to-serve

- Gross margin

- Revenue per user

- AI usage per user

## Cost Per Successful Outcome

Formula:

Cost per Successful Outcome

=

Total AI Cost

÷

Successful Outcomes

Example:

AI cost = $1,000

Successful outcomes = 8,000

Cost per successful outcome = $0.125

## Why Model Cost Alone Is Insufficient

A cheaper model can produce:

- more failures

- more retries

- more human escalations

- more rework

- lower retention

Therefore product economics must include downstream costs.

## Agent Economics

Agents may perform multiple operations for one user request.

Example:

Goal

→ Planning

→ Model

→ Tool

→ Observation

→ Model

→ Tool

→ Final result

The number of internal operations can significantly increase cost.

## AI PM Principle

Optimize total product economics rather than isolated model cost.

## Key Question

Does the additional AI cost create enough additional product value?

That value may come from:

- higher success

- less human work

- faster resolution

- higher retention

- increased revenue

- better customer experience
