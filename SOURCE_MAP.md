# Source Map

## Preservation Model

Each of the 75 original files has three traceable states:

1. The unchanged file in the original repository.
2. A categorized copy in this professional structure.
3. A hash-identical preservation copy under `99_Archive/Original_Structure/` using its original relative path.

No content has been consolidated in this migration phase. Detailed file-level mappings are maintained in [MIGRATION_REPORT.md](MIGRATION_REPORT.md).
