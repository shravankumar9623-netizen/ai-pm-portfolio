# Weekly Repository Maintenance Procedure

1. Record `git status`, branch, HEAD, upstream and stash state.
2. Back up the complete working tree, including untracked files and Git metadata.
3. Refresh remote references with `git fetch`; never blindly pull.
4. Compare local HEAD with `origin/main` and inspect ahead/behind commits.
5. Classify conflicts, local-only work and remote-only work before integration.
6. Validate Days, case studies, evidence register, resume, website and Figma references.
7. Scan tracked and untracked files for secrets and private data without printing values.
8. Run website lint and build.
9. Review changes and staged files explicitly.
10. Commit approved logical changes and push without force.
11. Verify GitHub commit, Vercel status, production commit and public routes.
12. Produce a dated health report containing unresolved evidence and confidentiality risks.

Never delete useful work, clear a stash, reset history or force-push without explicit authorization and a verified backup.
