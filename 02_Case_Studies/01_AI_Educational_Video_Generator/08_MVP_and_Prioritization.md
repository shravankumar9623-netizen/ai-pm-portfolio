# MVP and Prioritization

The original MVP specification file is empty, so the MVP below is a traceable synthesis of capabilities explicitly listed in the PRD and requirements sources. [Source: S18, S06, S07, S13]

## Proposed MVP Scope

1. Authentication and role handling. [Source: S07, S13]
2. Project creation. [Source: S13]
3. Question and solution PDF upload. [Source: S07, S13]
4. Question extraction. [Source: S07, S13]
5. Script and narration generation. [Source: S07, S13]
6. Annotation and storyboard generation. [Source: S07]
7. Preview, faculty review, and MP4 export. [Source: S07, S08]
8. Processing-status and completion notifications. [Source: S07]

## Prioritization Rationale

The sequence prioritizes the end-to-end faculty workflow documented in customer discovery, from input documents through review and export. [Source: S04, S07]

RAG grounding is documented as a quality-enhancement layer and can follow the basic generation workflow if approved content sources are not available at initial release. [Hypothesis] [Source: S09]

The repository contains no RICE, ICE, Kano, or opportunity-scoring exercise specifically applied to this product, so no numerical prioritization score is asserted. [Source: S18, S06, S07]
